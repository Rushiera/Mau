# 01 · 概览与能力全景

## CatHome4 是什么

**CatHome4 是一个本地运行的 AI 工作站。** 它把大模型变成一群能自己干活的「猫」——每只猫有人格、有工具、有自己的记忆，能在你的电脑上读写文件、写代码、查网页、看图片、执行命令，并在对话界面里把全过程展示给你。

宿主常驻桌面（系统托盘），数据全部留在本机。它不是一个聊天窗口，是一个**能持续干活的工作台**。

## 三层架构

| 层 | 形态 | 怎么变 |
|:--|:--|:--|
| **Runtime 层** | 固定 C#——数字电路机制（Tick / Cube / Inbox / OA / CommandBus / DataBox / FlowALC / FlowHandle / ThreadGuard） | 编译期变更 |
| **业务层** | `.mau` 语料 → 翻译 C# → 编译 dll——全部功能 | **热重载**（改完即生效，不重启） |
| **工具组层** | 每工具组一个独立 Flow（12 组现行） | 独立注册 / 热重载 / 退役 |

**自举循环**（核心工作流）：

```
LLM 写 .mau 语料 → 门禁验真（词法/解析/引用/图论/积木）→ 翻译 C# → 编译 dll
  → 热重载加载（宿主不重启）→ 观测（帧号可溯）→ 迭代
```

**哲学：** 大模型负责表达，确定性代码负责验真——表达自由，验证严格。业务 100% 语料化。

## 能力全景

| 面 | 能力 |
|:--|:--|
| **多猫** | 一进程多会话——各自人格、工具面、配置、端口，互不干扰 |
| **对话呈现** | 流式思考 / 工具调用 / 正文三态分呈 · 工具卡（参数 / 结果 / 耗时）· 轮末统计 · 图片直读 · 对话导航 · 桌宠 |
| **会话管理** | 新会话 / 清空 / 回滚 / 分支 / 续写 / 中止 |
| **工具面** | 文本与文件 · 代码（C# 语法树）· 终端（PowerShell）· 网页（搜索 / 抓取 / 下载 / 无头浏览器）· 图像（识别 / 直读）· 配置与管理 |
| **通道** | 浏览器面板 + 独立对话页 · QQ（文字 / 图片 / 文件 + `/new` `/last` `/info` `/ping`） |
| **自动化** | 定时与延迟（一次性 / 周期）· 任务追踪（Note）· 加载包（pack） |
| **数据隐私** | 全部本机 · 密钥分离存放 · 日志按次落盘 · 正式实例数据独立于仓库 |

## 边界（明确不做什么）

| # | 边界 | 含义 |
|:--:|:--|:--|
| 1 | **宿主只承载循环基建** | 业务逻辑 100% 在语料——宿主 C# 里不放业务 |
| 2 | **直连、不经中转** | 自填 LLM 端点与密钥，无中间平台；可选能力（联网 / 供应商）不入宿主核心 |
| 3 | **数据全本机** | 无云端同步；密钥单独存放，不进对话、不进快照 |
| 4 | **正式实例在仓库之外** | 部署目录与仓库解耦——重建 / 删除仓库不影响运行数据 |
| 5 | **宿主重启经特权面** | 只经管理面（Majordomo）触发，不由任意路径发起 |
| 6 | **能力可裁剪** | 工具按组加载、逐猫裁剪——给猫的权限范围由你定 |
