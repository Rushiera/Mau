# CatHome4 用户手册

> 面向**使用者**与**接手改造者**的能力全景与基础用法——不需要了解内部知识库（CCBP），读完即可上手。
> 对应版本：1.8.95 · 仓库：`mau`（Gitee `wu_lisha/mau`，GitHub 镜像 `WuLiSha-HUB/mau`）

---

## 这本手册给谁看

- **初次使用者**——想知道 CatHome4 是什么、能做什么、怎么开始。
- **接手改造者**——要动 CatHome4 的语料与代码，需要知道工具怎么用、红线在哪。

手册讲**能力边界**与**基础用法**；实现细节见仓库源码与项目规格文档。
